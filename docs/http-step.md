# Отправка данных по HTTP

За отправку отвечает `src/network/http_sender.cpp`. Он получает готовые записи
из `ActivityQueue`, преобразует их в JSON через
`src/serialization/activity_packet.cpp` и отправляет на локальный сервер.

Текущий адрес сервера: `http://127.0.0.1:8080/`. Используется обычный HTTP без
TLS.

<hr>

## Как формируется пакет

Основной поток ждёт одно из двух событий:

<ul>
  <li>в очереди накопилось 10 записей;</li>
  <li>прошло 30 секунд.</li>
</ul>

После этого из очереди копируются до 10 первых записей. По таймеру отправляется
и неполный пакет. Копирование не удаляет
данные: они остаются в очереди до успешного ответа сервера.

Во время HTTP-запроса поток сбора продолжает добавлять новые записи в очередь.

<hr>

## Отправка и повторные попытки

Пакет отправляется методом `POST /` с заголовком
`Content-Type: application/json`.

Записи считаются доставленными только после ответа с кодом `2xx`. После такого
ответа отправленные элементы удаляются из очереди.

При сетевой ошибке или другом HTTP-статусе:

1. записи остаются в очереди;
2. тело JSON не изменяется;
3. повторная попытка выполняется через 5 секунд.

Тайм-ауты подключения, чтения и записи равны 2 секундам каждый. Это отдельные
тайм-ауты операций, поэтому полный запрос может занимать больше 2 секунд.

Очередь рассчитана на 100 записей. Неподтверждённые записи тоже занимают место.
Если очередь заполнена, новые замеры пропускаются.

<hr>

## Демонстрационный сервер

Файл `tools/demo_server.cpp` содержит простой сервер для локальной проверки. Он:

- принимает `POST /`;
- проверяет `Content-Type` и JSON;
- печатает пакет в консоль;
- отвечает кодом `204 No Content`.

Сервер не сохраняет данные после завершения.

Для запуска соберите проект, как указано в [основном README](../README.md).
